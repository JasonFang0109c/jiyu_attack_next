# GUI 使用说明

## 直接运行 Python 版本

在项目根目录打开 PowerShell，安装依赖并启动：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.gui
```

也可以执行 `powershell -ExecutionPolicy Bypass -File .\scripts\run_gui.ps1`，由启动脚本自动使用项目虚拟环境。界面包含“发送测试”和“本机工具”两个工作区，提供消息与命令编辑、文件导入、循环发送、设备操作、日志查看与导出。

## 运行打包后的 EXE

已构建的文件位于：

```text
output\JiyuUdpTest.exe
```

直接双击即可运行，无需安装 Python 或 PySide6。EXE 为单文件窗口程序，首次启动会解压运行时资源，可能需要数秒。

## 界面行为说明

- 发送与取消按钮固定在窗口底部。任务在后台执行，可查看日志、请求取消；关闭窗口时会先结束当前任务再退出。
- 消息支持多行和长文本自动分条。每条报文最多 448 个 UTF-16 单元，分条后的消息由接收端独立显示，脚本不负责合并或确认送达。
- 消息、命令与重启或关机指令可以组合发送。界面只允许重启与关机二者选一。
- 命令最多容纳 163 个 UTF-16 单元，界面实时显示使用量；超过容量会提示错误。
- “本机工具”只操作运行程序的电脑，不向目标发送报文。防火墙操作需要管理员权限。
- 反向 Shell 功能保留在 CLI 的 `-e nc` 中，GUI 不提供对应入口。
- 日志中的“发送完成”只表示本机发送调用完成，不代表目标已收到或执行成功。

EXE 的编译过程见 [构建说明](BUILD.md)，应用目录与模块职责见 [项目结构](STRUCTURE.md)。
