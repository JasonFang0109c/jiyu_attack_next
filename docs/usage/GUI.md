## 使用须知

启动 GUI 时会先弹出“使用须知”，声明本工具只用于已获授权的教学环境测试与安全研究，违规或恶意使用与作者及本项目无关。窗口内提供两个按钮：

- **同意并继续**：关闭提示并进入主界面，之后照常使用各功能页面。
- **不同意，退出**：立即结束本次启动，不创建主窗口，也不写入设备备注与运行日志。

该提示每次启动都会出现，不记忆“已同意”状态；命令行模式不弹出提示。提示文字与 [README](../../README.md) 首页的警告一致。

同意后会先显示启动遮罩，再进入主界面：遮罩以项目图标居中，下方依次是应用名与版本号，底部是一条不确定进度条和“正在准备界面…”提示。遮罩跟随主窗口尺寸变化并始终盖在界面之上，最短停留 800 毫秒，避免界面搭建期间露出半成品布局；界面就绪后自动关闭，不需要手动操作。遮罩只在图形界面启动时出现，命令行模式没有。

## 源码运行

在项目根目录安装依赖并启动：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app
```

也可执行 `powershell -ExecutionPolicy Bypass -File .\scripts\run_gui.ps1`，由启动脚本自动使用项目虚拟环境。需要调试命令行模式时，运行 `python -m app -h`；打包后的 EXE 已包含两种模式，使用时无需 Python。

界面使用 [PySide6-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets/tree/PySide6) 构建，采用 Fluent 侧边导航和统一圆角分区卡片。

## 首页

启动后默认停在首页。顶部直接是大标题与一行说明（工具定位与版本号），下方并排四个快捷卡片：“设备备注”（进入设备备注页）、“项目仓库”“使用文档”“问题反馈”，后三个用系统默认浏览器打开对应网址。

再往下按“远程攻击”“教师端模拟”“本机工具”分组，用两列卡片列出各功能页，卡片左侧是纯图标，右侧是页面名与一句话说明，点击即切换到该页。卡片圆角统一取 8 像素，底色跟随主题；整张卡片都是点击区域，图标与文字不会拦截鼠标。页面内容超出窗口高度时整页滚动；滚动条平时不显示，滚动时才短暂出现一条很细的淡色滑块，停下约一秒后再次淡出。

<br>

## 设备操作

“设备操作”页在重启、关机与注销三项里选一项，下方是解析后的目标预览（地址与 UDP 端口）。重启与关机会带上三个可选参数：

| 控件 | 默认值 | 说明 |
| --- | --- | --- |
| 倒计时秒数 | `0` | `0` 立即执行，最大 86400 秒（一天）；学生端会在倒计时期间显示提示文字 |
| 强制关闭程序 | 勾选 | 取消勾选表示等待程序自行退出，等待超时后仍然关机 |
| 提示文字 | 空 | 关机或重启倒计时期间显示在目标屏幕上的文字 |

重启与关机都走应用命令通道（cmdId `0x13` / `0x14`），因此这些参数能真正下发到学生端；注销没有对应的极域命令号，仍然用远程命令通道执行 `shutdown /l`，所以选中注销时三个参数控件会被禁用。发送前会弹出确认框，写明倒计时、是否强制与提示文字。发送完成后在页面状态行与日志里记录目标数量与结果。

<br>

## 应用命令

“应用命令”与“学生信息”同属侧边栏的“教师端模拟”分组，把几条只有教师端才会下发的命令补齐到图形界面。顶部先选动作，右侧填会话频道；下方会随动作换表单，底部“发送命令”把负载发给目标地址里的全部设备。

| 动作 | 表单 | 投递方式 |
| --- | --- | --- |
| 远程运行程序 | 程序路径、启动参数、窗口状态 | 单播应用命令（cmdId `0x0F`） |
| 打开网址 | 网址或本地路径，网址缺协议时按 `http://` 补全，`C:\...` 与 UNC 路径原样下发 | 单播应用命令（cmdId `0x18`） |
| 终止进程 | 进程号、是否强杀 | 单播 MESS 上报请求（进程号模式） |
| 黑屏并锁定键鼠 | 是否锁键鼠、自动解除秒数（`0` 表示不自动解除）、提示文字 | 会话频道组播，锁键鼠时再补一条应用命令（cmdId `0x06`） |
| 解除黑屏 | — | 会话频道组播 |
| 退出学生端 | — | 单播应用命令（cmdId `0x15`） |
| 关闭所有程序 | — | 单播应用命令（cmdId `0x02`） |

黑屏与解除黑屏必须走会话频道组播，单播不生效，所以这两项的“会话频道”要和学生端所在频道一致；其余动作使用页面上方的目标地址与 UDP 端口。锁键鼠的解除不能靠再发一次“黑屏”并把锁去掉——学生端只把 `lock_input=1` 当作上锁，解锁要用“解除黑屏”。退出学生端、关闭所有程序与黑屏这三类操作会在发送前弹出确认框。

自动解除秒数除写进报文外，界面自己也会按秒数排一个定时器：黑屏发送成功后开始计时，到点自动补发“解除黑屏”并提示结果。秒数填 `0` 时不排定时器，黑屏会一直保持，需要手动点“解除黑屏”。退出程序会取消尚未到点的定时器。

## 学生信息

“学生信息”页充当教师端模拟：点“发现学生”会按会话频道周期发送在线宣告并监听登录，页面上显示频道与教师名，教师名就是学生端屏幕上看到的名称。学生登录后会自动回一条会话应答、缩略图策略和教师端控制信息，随后教师端请求一次全量上报，因此发现阶段结束时列表里已经有计算机名、登录用户、系统、CPU 与内存。

在列表里选中一台学生机，下方“进程”与“窗口”两个视图会显示该机上报名单；点“刷新所选学生”可以重新拉取一次，点“结束所选进程”会先确认再发送结束请求。窗口视图只用于查看与人工核对，页面不提供按窗口关闭应用的操作。

“结束所选进程”旁边的输入框可以填进程名：填了就按进程名在该学生已上报的进程列表里匹配（先忽略大小写精确匹配，匹配不到再按子串匹配），命中的进程逐个下发结束请求，确认框里会列出命中的进程；留空则结束下方进程视图里选中的那一行。

顶部的“全员缩略图”对当前列表里每台学生各请一帧缩略图，收齐后统一显示在一个独立窗口里：卡片按三列排布，显示地址、计算机名/登录用户/系统与缩略图，没收到或解码失败会写明原因，底部汇总“共 N 台学生机，收到缩略图 M 台”。列表为空时先按当前频道发现一轮再拉取。

这一页只管发现与进程、窗口；屏幕画面与接管键鼠在“屏幕画面”和“远程接管”两页里，两页自己填写目标地址，不依赖这里的选择。学生端把屏幕切成 1 KB 分片发送，接收端按偏移重组，缺片时用重传应答请求补齐。JPEG 帧直接显示；H.264 帧经 PyAV 解码成位图后同样显示在窗口里，解码失败只记录日志，不影响继续接收。观看窗口里的“接管键鼠”会把桌面控制模式切到接管，学生端随后锁定本机键鼠、只接受来自观看端的输入；按钮接管后变成“解除接管”，点一下即恢复。接管期间画面区直接接收鼠标与键盘事件：移动、左中右键的按下与抬起、滚轮都按画面实际显示的矩形折算成学生端坐标（落在黑边上的点不发送），按键按扫描码与虚拟键码转发，方向键这类扩展键会带上扩展标志。关闭窗口会发送停止指令并断开连接。

### 屏幕画面与远程接管

“屏幕画面”页自己填目标地址与会话频道，三个入口互不影响：

1. “检查端口”在后台做一次 `4806/TCP` 连接探测，用来区分“端口没开”“被防火墙挡了”和“地址写错”，不发送画面请求。等待连接期间界面仍可操作，结果对应点击时填写的地址，并保留在页面状态行。
2. “刷新缩略图”按缩略图策略请求一帧画面，收到后直接显示在页面下方。
3. “观看画面”另开一个窗口，向学生端申请桌面传输并从 `4806` 端口连续接收画面。

学生端把屏幕切成 1 KB 分片发送，接收端按偏移重组，缺片时用重传应答请求补齐。JPEG 帧直接显示；H.264 帧经 PyAV 解码成位图后同样显示在窗口里，解码失败只记录日志，不影响继续接收。

“远程接管”页对填写的地址打开观看窗口，连接成功并显示第一帧后自动接管键鼠，按钮随后变成“解除接管”。从“屏幕画面”页打开的观看窗口则保持只读，可点“接管键鼠”手动接管。接管期间学生端锁定本机键鼠、只接受来自观看端的输入；画面区直接接收鼠标与键盘事件，移动、左中右键、滚轮都按画面实际显示的矩形折算成学生端坐标（落在黑边上的点不发送），按键按扫描码与虚拟键码转发，方向键这类扩展键带扩展标志。点“解除接管”恢复学生端自己的输入并继续观看；关闭窗口会解除接管、停止推送并释放连接。连接与清理在后台执行，关闭后到达的旧画面与接管请求会被丢弃。同一地址与频道复用一个观看窗口；关闭后立即重开会等待旧连接释放，再请求新画面。修改控制端口后再次打开该目标会先解除已有接管，再使用新端口。退出主程序会同时关闭隐藏的观看窗口，并等待连接释放后退出。

## 聊天消息

“聊天消息”走教师会话的聊天通道（MESS 类型 `0x800`），与“文本消息”页不是一回事：“文本消息”发的是重放的桌面消息模板，不需要学生登录、单向弹出；“聊天消息”要求目标已经登录教师会话，文本按 UTF-16 编码，码元数含结尾空字符，否则学生端可能只显示第一个字。发送前会先宣告一轮并等待登录，目标没登录时直接提示“目标没有登录教师会话”。

<br>

## 关闭窗口

“关闭窗口”让目标学生端关闭指定窗口，进程本身继续运行；要结束进程用“应用命令”页的“终止进程”。输入框既可以填窗口句柄，也可以填窗口标题关键字：

- 句柄写十进制或 `0x` 开头的十六进制，例如 `0x00120A3C`，从“学生信息”页的窗口视图里读；按句柄关闭时直接下发，只发一次。
- 标题关键字会先在“学生信息”页已缓存的窗口列表里匹配（先忽略大小写精确匹配，匹配不到再按子串匹配），缓存里没有的地址会先发现一轮再匹配；没有命中时提示先刷新学生信息，不会盲发。

<br>

## 反弹终端

“反弹终端”是本机监听、目标主动连回的命令行，不是一次性的“远程命令”：

1. “本机地址”是目标要连回来的地址，点“开始监听”后在空闲端口起一个终端服务，同时起一个只提供启动脚本的小型 HTTP 服务。
2. “发送连接命令”经远程命令通道让目标下载并执行脚本，目标随后连回，页面状态变成“已连接”，等待输入就绪的提示符。
3. 在底部输入框里逐条发送命令，输出实时回显在控制台里；点“停止监听”断开连接并关掉两个服务端。

下发的连接命令只有一百多个字符，因为远程命令通道单条上限是 163 个字符，所以启动脚本不内联在命令里，而是由本机临时 HTTP 服务提供。目标需要能访问本机地址与端口。

缩略图原始数据是自下而上的 DIB，且色度通道被取反，直接打开会上下颠倒、颜色发绿。界面显示前会用 Pillow 做翻转与色度还原；Pillow 属于组件库 `[full]` 的依赖，缺失时界面只显示原图并提示无法修正。

<br>

## 目标地址

目标地址按 IPv4 四段分开填写，段间自动以 `.` 连接；前三段分别填写 0–255，最后一段支持单个末段、末段范围（如 `1-10`）和 `/24` 网段（如 `0/24`）。在四个地址输入框中按回车或点号 `.` 会依次跳到下一段（点号不会写进数字框），在最后一段按回车会进入端口输入框。

目标地址和 UDP 端口在文本消息、文件传送、设备操作、远程命令与应用命令之间同步；发送轮数和轮次间隔仅在文本消息、设备操作与远程命令这三个可循环发送的页面之间同步。消息、命令及设备选择分别保留，切换页面不会清空草稿。窗口较窄时侧边栏会收窄为图标并保留分组图标，重新展开后恢复各分组之前的收展状态，窗口最小尺寸为 960 × 640。

目标地址也可以填写运行程序的电脑自身 IPv4，用于没有第二台测试设备时验证发送流程；本机没有学生端监听对应端口时不会执行操作。需要自动校验报文收发时，运行仓库中的 `scripts/test_local_ip.py`，说明见[开发与提交规范](../dev/CONTRIBUTING.md#本机-ip-自测)。

## 文件传送

“文件传送”页面把本机勾选的文件或文件夹发送到目标电脑的当前用户桌面：

1. 填写目标 IPv4 地址、末段范围（如 `1-10`）或 `/24` 网段，也可选择设备备注；任务会按解析出的目标逐个传送。
2. 点击“添加文件”可一次选择多个文件，点击“添加文件夹”可添加整个文件夹；待传送列表以文件树展示，每个文件和文件夹都有复选框，列表标题栏第一格的复选框与行内复选框大小一致，用于全选或清空全部选择。
3. 新添加的文件和文件夹默认处于勾选状态。未勾选的条目平时显示文件或文件夹图标；鼠标悬停在名称列时，图标切换为复选框，离开后未勾选条目恢复图标。已勾选和部分勾选的文件夹持续显示复选框。
4. “传送文件”只传送当前勾选的文件；只勾选某个文件夹时，会传送该文件夹下的全部文件并保留目录结构。
5. 待传送列表顶部的删除按钮只移除勾选的文件或文件夹（不会删除源文件），未勾选任何条目时按钮不可用。
6. 点击“传送文件”，确认目标与文件后开始任务。目标端通过 Windows 自带的 `curl` 下载，进度显示在页面和运行日志中。
7. “文件传送”标题右侧的信息图标悬停后显示简要说明。

传送时 GUI 自动检测发送端 IP，并为每个目标启动一个仅在本机任务期间存在的随机令牌 HTTP 服务；界面不提供发送端 IP 输入框。检测会忽略 `198.18.0.0/15` 等虚拟或基准测试网段，并在出口地址不可用时选择与目标网段更接近的真实局域网地址。UDP 命令未得到响应时最多重发 3 次，避免单次丢包导致任务无响应。

目标电脑不需要开放入站端口，只需允许执行远程命令、提供 Windows 自带的 `curl.exe`，并允许其主动访问运行日志中显示的发送端 IP 与临时 TCP 端口。目标端不使用 PowerShell，因此不需要修改 PowerShell 执行策略。目标保存到当前登录用户桌面，不自动打开文件，也不会回传执行结果。运行日志中每个目标对应的“文件传送服务已启动”地址就是该目标需要访问的发送端 IP；失败信息会区分目标未访问文件服务、已取脚本但未下载，以及下载中断。任务可取消，取消或超时后会停止临时文件服务。

多个目标按顺序逐个传送，每个目标单独等待下载并显示当前目标进度。某个目标失败后会记录失败原因并继续尝试其余目标，全部目标处理结束后统一显示成功或失败结果；确认框会显示解析后的目标数量。`120` 秒超时按单个目标计算。

## 设备备注

“设备备注”页面用于把常用的 IPv4 地址映射为易读名称，标题右侧的信息图标悬停后显示备注用途和支持的地址格式：

1. 填写备注名和 IP 地址，点击“添加备注”。IP 地址同样分为四段，支持单个 IPv4、末段范围（如 `1-10`）和 `/24` 网段；备注名输入框按回车会进入地址第一段，地址最后一段按回车会保存。
2. 选中表格中的备注，可执行“设为当前目标”“修改”或“删除”；双击行也可直接修改。
3. 在任意远程页面点击目标地址右侧的“选择设备”，从弹窗的下拉列表中选择备注；目标地址四段会填入解析后的 IPv4，下方显示“备注名 → IPv4”的解析结果。
4. 修改备注名或 IP 后，当前目标如果引用该备注，会自动同步；删除正在引用的备注会清空当前目标。

备注名不区分大小写，不能为空、不能用纯 IP 格式，且同一名称只能对应一个地址或地址范围。备注可保存单个 IPv4、末段范围或 `/24` 网段；目标地址框仍可手动输入这些格式。备注与运行日志保存在程序所在目录的 `JiYuAttackNextData` 子文件夹中（源码运行时为项目根目录），重启 GUI 后仍会保留；该目录由 `.gitignore` 排除。只把 EXE 移到其他位置、不一起移动该文件夹时，会按默认配置启动。实际发送、确认框和设备预览始终使用解析后的地址，日志会记录备注名及解析结果。

## 运行打包后的 EXE

已构建的文件位于 `output\JiYuAttackNext.exe`，同一个 EXE 包含 GUI 与 CLI 两种模式，无需安装 Python 或 PySide6：

- **GUI**：双击（无参数）打开图形界面，不显示控制台窗口。
- **CLI**：在终端带参数运行，保留控制台窗口并显示输出，例如 `.\JiYuAttackNext.exe -ip 10.49.151.29 -msg "Hello"`。

cmd 在 EXE 所在目录可直接写 `JiYuAttackNext.exe ...`；PowerShell 需要 `.\` 前缀，或使用绝对路径。CLI 参数与示例见 [CLI 模式使用说明](CLI.md)。EXE 为单文件程序，首次启动会解压运行时资源，可能需要数秒。

程序首次写入备注或日志时，会在 EXE 所在目录创建 `JiYuAttackNextData` 子文件夹，其中 `settings.json` 保存设备备注与界面设置，`runtime.log` 保存界面运行日志，`cli.log` 保存命令行模式的运行日志。`settings.json` 是带注释的 JSON：`core` 组存放设备备注，`gui` 组存放界面设置，允许手写 `//` 与 `/* */` 注释和尾逗号，程序保存时会重写整个文件，手写注释只在下次保存前有效。若 EXE 所在目录不可写，备注和日志会保存失败并在界面提示；请将 EXE 放到可写目录后运行。

## 系统托盘与退出

- 第一次关闭主窗口时，程序会弹出一次提示，可选择“最小化到托盘”或“直接退出”；选择结果会保存到 `settings.json` 的 `gui/window/close_behavior`，之后关闭窗口不再重复询问。
- 选择“最小化到托盘”后，点击窗口关闭按钮会静默隐藏主窗口，不弹出托盘提示，后台任务继续执行；双击托盘图标或通过右键菜单选择“显示主窗口”可恢复界面。
- 托盘右键菜单中的“退出”会结束当前任务并真正退出程序：托盘图标、单实例服务与后台线程一起释放，进程随即结束，不在任务管理器中残留。退出清理只执行一次，事件循环结束后的收尾不会重复写“应用退出”日志。
- 在“设置”页的“关闭时最小化到托盘”选项中，可随时通过开关切换是否在关闭窗口时最小化到系统托盘。开关只显示状态，不显示附加文字。
- 如果系统托盘不可用，关闭窗口会直接退出程序。

## 界面行为说明

- 每个页面底部固定显示状态、日志入口、取消操作和当前页面的主操作按钮。任务在后台执行，可查看日志、请求取消；关闭时最小化到托盘会隐藏窗口并继续执行任务，首次提示选择“直接退出”、托盘菜单“退出”或关闭该开关时会先结束当前任务再退出。
- 消息支持多行和长文本自动分条。每条报文最多 448 个 UTF-16 单元，分条后的消息由接收端独立显示，脚本不负责合并或确认送达。
- 每个页面只发送当前页面的内容，避免切换页面后把不相关的草稿一起发送。重启、关机与注销只能选择一项。
- 远程任务执行期间主操作按钮仍可用：再次发送不会覆盖或丢弃当前任务，而是按点击顺序加入队列，等当前任务结束后依次执行。页面状态会显示排队位置；点击“取消”会同时取消当前任务和尚未开始的排队任务。
- 命令最多容纳 163 个 UTF-16 单元，界面实时显示使用量；超过容量会提示错误。
- “本机信息”和“防火墙”只操作运行程序的电脑，不向目标发送报文。防火墙操作需要管理员权限；未以管理员身份运行时，操作会弹出 UAC，由隐藏助手执行，GUI 本身不会以管理员权限重启。
- 发送设备指令前会显示目标数量、端口和操作类型并要求二次确认。注销没有独立的极域报文，而是通过远程命令通道执行 `shutdown /l`，依赖目标允许执行远程命令。
- 发送结束后右上角提示与页面状态显示成功、失败的设备数量：任一目标返回 ICMP 不可达（端口无人接收或主机不可达）、或在补充的 ICMP 回显与 ARP 解析里都找不到回应时，提示“部分目标失败”并写入警告日志，否则提示“发送完成”。判定依据只有网络反馈与主机是否在线，两者都不代表对方执行成功。
- “关于”页顶部的图片与项目名称区域不绘制圆角卡片背景，标题下方依次显示与 [README](../../README.md) 首页一致的三行说明文字（工具定位、技术栈与授权提示）；下方依次显示作者卡片，以及“仓库信息”“版本信息”“组件信息”“许可信息”四张独立卡片。仓库信息合并主仓库与两个来源仓库共三个链接，两个来源仓库共用第一条的“来源仓库”标题、都带 GitHub 图标；版本信息合并版本与构建时间；组件信息列出 PySide6 与 Fluent Widgets 的版本；许可信息给出许可证名称（可跳转 GNU 官方说明）与版权声明。四张卡片的标题与首行之间留白大于行与行之间，行高以超链接按钮的自然高度为准，文字行与链接行等高且链接下划线完整显示。内容超出窗口高度时整页（含“关于”标题）可上下滚动，不会压缩卡片布局；滚动条贴住窗口右缘，轨道贯通整个页面高度，平时不显示，滚动时才短暂出现一条细淡滑块。构建时间取自打包时写入的构建时间标记，源码运行时显示“源码运行”；版本号在 EXE 中取自打包时写入的版本，源码运行时显示 `app.__version__`。
- 程序同一时间只允许运行一个实例（含托盘中的隐藏窗口）。再次启动 EXE 时不会打开第二个窗口，而是唤醒已运行的主窗口并置于前台。
- “设置”页底部的“清除数据”会先显示确认框；确认后删除程序数据目录（包括设备备注、界面设置与运行日志），取消则不做修改。清除后关闭窗口行为恢复为默认的最小化到托盘，首次关闭提示也会重新出现，窗口大小与位置回到默认并居中显示；本次运行的文件日志暂停，重启程序后恢复写入。
- “设置”页顶部的“界面主题”卡片先给颜色模式，再给“窗口材质”下拉框，样式与“关于”页的仓库信息卡片一致。窗口材质有三项，默认 Mica（云母）：Mica（云母）由系统按桌面壁纸采样，需要 Windows 11（内部版本 22000 及以上）；Acrylic（亚克力）实时模糊窗口下方的内容，既透出桌面壁纸，也透出压在下面的其他应用窗口，切换或拖动下层窗口时背景会跟着变，需要 Windows 10（内部版本 17763 及以上）；纯色（无材质）关闭材质，改用不透明底色，任何系统都可用。当前系统不支持的选项在下拉框里置灰。卡片标题用默认的正文字号，下方的“颜色模式”“窗口材质”标签再小一档，两行之间留出的间距大于普通设置卡片，视觉上与仓库信息卡片一致。选择写入 `settings.json` 的 `gui/window/material`，下次启动沿用；早期版本只有“背景模糊”开关，读取旧键 `gui/window/mica_enabled` 时按开启换算成 Mica、按关闭换算成纯色。
- 主窗口退出时记住位置与大小，下次启动恢复；显示器分辨率或排列变化导致原位置越界时，窗口会被夹回当前屏幕可用区域。主窗口最小化时会跳过一次记录，避免把任务栏图标位置当成窗口位置。
- 弹窗按父窗口外框居中显示，主窗口移动或缩放后弹窗始终落在主窗口中央，并保证完整可见；启动时的使用须知还没有主窗口，按屏幕居中。
- “设置”页的“运行日志等级”决定写入阈值，默认 `WARNING`，可选 `INFO`、`WARNING`、`ERROR`：调低到 `INFO` 后会记录启动、任务开始与完成这类记录。`DEBUG` 不在选项里，它只存在于随发布一起提供的 `JiYuAttackNext_Debug.exe`；那个版本固定从 `DEBUG` 起全量记录，下拉框显示为不可用。
- 日志页提供两级筛选：“全部功能”按功能分类筛选，“全部级别”按当前版本可用的等级精确筛选，搜索框会在时间、级别、功能、内容、线程和输出位置中匹配关键词。多个筛选条件同时生效。
- 日志表每行带复选框，可多选；表头第一格（时间列之前）同样带复选框，用作全选：勾选表头会选中当前筛选结果，任意一行取消勾选后表头自动取消，取消表头会清空全部选择（包括被筛选条件隐藏的行）。批量操作只能针对已勾选的记录。
- 日志页上方的导出和删除按钮只作用于勾选记录：导出按规范文本导出选中日志，删除在确认后删除选中记录并同步重写日志文件；没有勾选记录时两个按钮均不可用。
- 运行日志在启动时从 `runtime.log` 载入最近 2000 条记录，新记录实时追加。格式为 `2026-10-23 12:34:56.789 [12345] [MainThread] INFO    app.gui.app.MainWindow:123 - [文本消息] 开始发送：192.168.1.20，端口 4705，1 轮`，多行内容与异常堆栈以缩进续行写入；旧版 JSONL 日志会自动读取并迁移为规范文本。
- 日志文件在本次运行期间保持打开，每条记录写入后立即刷盘，进程异常退出也不会丢掉已写入的内容；日志页回填历史记录与连续追加时合并刷新，滚动只在最后落到最新一条，记录很多时打开日志页和刷屏都不再逐条重绘。
- 日志字段包括毫秒级本地时间、线程 ID、线程名称、级别、输出模块与行号、功能分类、消息和可选详情。异常会记录异常消息与 Python 堆栈，便于复现和定位问题。
- 关键操作都会留下记录：启动与界面就绪、单实例服务创建与第二次启动的唤醒请求、日志系统初始化、托盘图标创建与移除、主题、窗口材质与关闭行为变更、窗口位置恢复、设备备注的增删改、任务加入队列与后台线程启动结束、发送与传送的开始和完成、本机查询与防火墙操作、导出与删除日志、清除本地数据、退出与退出码。
- 取消类操作（取消文件选择、取消确认框、取消日志删除或导出、取消消息导入导出、取消设备备注编辑）写入 `INFO`；已有任务运行时被拒绝的重复操作、未勾选记录的批量操作、配置或备注写入失败写入 `WARNING`；线程内的参数快照、进度回调、线程开始结束与耗时写入 `DEBUG`，只有 `_Debug` 版本会记录。
- 后台线程（`SendWorker`、`TaskWorker`）在启动时注入日志存储，线程内记录目标、端口、轮数、负载长度、耗时与异常类型；失败时仍由页面状态与右上角提示给出可读消息，堆栈同时写入运行日志。
